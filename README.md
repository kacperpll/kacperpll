# Kacper Duniewicz

I'm a front-end lead from Poland. Most of my work is taking over Angular applications that someone else built and getting them back into shape.

Right now that is a multi-tenant B2B portal. I took it from Angular 18 to 22, merged three copies of the codebase into one shared core, and added Vitest so the app finally has a test baseline.

What I usually work on:

- an Angular app several major versions behind
- the same app copied into several repositories
- code with no tests and nobody keen to write the first one
- a team without a code standard, or with one that nobody follows

## On this profile

[angular-coverage-guard](https://github.com/kacperpll/angular-coverage-guard) is a Claude Code plugin I built for the third problem on that list. It finds untested code in Angular + Vitest projects, ranks the gaps by risk rather than by percentage, and writes the missing tests once you approve them.

Most of my client work lives in private repositories, so this profile only shows what I build on my own time.
